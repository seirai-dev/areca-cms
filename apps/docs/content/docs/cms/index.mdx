This guide is for the people who write and manage a client's website content in the Areca CMS. You do not need technical skills to use it. You never edit the website's code. You work with forms, text and images, and Areca publishes your approved content to the live site.

## Who this guide is for

Your role decides which buttons you can use. Where a button is not available to you, it is shown as disabled, usually with the reason.

- **Editors** write and edit drafts, upload images, add SEO details and preview their work.
- **Owners** do everything an editor does. They also mark entries as ready, schedule them, start Go live, archive and delete entries, and manage the people on their client's team.
- **Agency admins** work across every client and site. They set up clients, sites, content types, branding and AI settings.

The full list of permissions is in [Roles and permissions](/docs/security/roles-and-permissions).

## The editor workflow at a glance

Content moves through four steps. Nothing reaches the live website until an owner approves it and starts a release.

<Steps>
<Step>

**Write.** Create an entry or edit an existing one. Changes save automatically, and they stay in the CMS as a draft. The live website does not change.

</Step>
<Step>

**Preview.** Open the draft on the website to check how it looks before anyone else sees it.

</Step>
<Step>

**Mark as ready.** An owner approves the entry for the next release.

</Step>
<Step>

**Go live.** An owner starts a release. Every ready change on the site is published together, and the website is rebuilt and deployed.

</Step>
</Steps>

An owner can also schedule a ready entry for a later time. The release then starts by itself at that time.
